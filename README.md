## 📌 Project Overview

This project establishes and verifies a functional AWS operational environment using the **AWS Management Console** and **AWS Command Line Interface (AWS CLI)**.

It focuses on foundational cloud operations skills required by cloud support engineers, including account access verification, AWS regional configuration, identity validation, resource discovery, and operational documentation.

The project follows practical cloud support workflows, emphasising technical verification, security awareness, troubleshooting, and evidence-based reporting.

## 🎯 Project Objectives

- Verify AWS CLI installation and environment readiness.
- Confirm the configured AWS Region.
- Validate authenticated AWS identity access.
- Understand AWS global infrastructure and regional operations.
- Practise AWS resource discovery and operational verification.
- Document implementation procedures and technical findings.
- Maintain evidence of completed practical exercises.

## 📚 Project Scope

The project is organised into the following learning and implementation areas:

1. AWS account foundations and environment verification.
2. AWS global infrastructure: Regions and Availability Zones.
3. Global services versus regional services.
4. AWS account operations and identity context.
5. AWS CLI configuration, profiles, and authentication.
6. AWS resource discovery and inventory.
7. AWS operational troubleshooting and documentation.
8. Final project review, evidence audit, and GitHub presentation.
